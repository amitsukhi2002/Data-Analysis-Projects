# 📊 Sales & Finance Analytics Dashboard (Excel)

## 📌 Project Overview

This project focuses on building interactive **Sales** and **Finance** reports using Microsoft Excel and Power Pivot. The reports provide valuable business insights by analyzing customer performance, market performance, sales trends, and financial performance across different fiscal periods and markets.

The project demonstrates end-to-end data analysis, from data preparation using ETL techniques to creating analytical reports that support business decision-making.

---

# 🎯 Project Objectives

## Sales Report

- Create a Customer Performance Report
- Compare Market Performance against Sales Targets
- Monitor sales performance using key KPIs
- Identify sales trends and customer buying patterns
- Support business decisions regarding discounts and negotiations
- Identify high-potential countries and markets for expansion

## Finance Report

- Create Profit & Loss (P&L) reports by Fiscal Year
- Create Profit & Loss (P&L) reports by Month
- Generate Profit & Loss (P&L) reports by Market
- Analyze financial performance over different periods
- Support budgeting, forecasting, and strategic planning
- Compare financial performance with previous periods

# 🔄 ETL Process

The project follows the ETL (Extract, Transform, Load) workflow:

1. Extract data from multiple sources
2. Clean and transform data using Power Query
3. Load transformed data into the Excel Data Model
4. Build relationships using Power Pivot
5. Create calculated columns using DAX
6. Design analytical reports and dashboards
