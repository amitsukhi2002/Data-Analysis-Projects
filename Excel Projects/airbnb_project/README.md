### 🗺️ Airbnb Performance Analysis

### 📌 Project Overview

This project analyzes global Airbnb listing data provided by Maven Analytics to uncover trends in pricing, host characteristics, and market supply across different cities and time periods. The primary objective is to evaluate operational patterns—such as host behaviors, booking constraints, and historical listing growth—to guide strategic rental management. 

### 📊 Dataset

* **Source:** Maven Analytics
* **Format:** Microsoft Excel (.xlsx)
* **Contents:** Multi-city data encompassing individual property listings, historical timelines, geographic regions, review metrics, and detailed host statuses.

### 🛠️ Tools & Tech Stack

* **Software:** Microsoft Excel
* **Data Modeling:** Power Pivot (Data Model)
* **Calculations:** Data Analysis Expressions (DAX) for advanced measures and custom KPIs.
* **Data Aggregation:** Power Query for Extract, Transform, Load (ETL) processing.

### 📂 Project Structure & Deliverables

The core analytical findings are systematically broken down into targeted performance reports: 

* 📄 Analysis.pdf - The master compilation of the data project.
* 🏙️ Avg Price By City.pdf - Evaluation of geographic pricing differences.
* 📅 Avg price by year.pdf - Trend analysis of listing costs over historical years.
* ⭐ Top Properties by average ratings.pdf - Identification of the highest-rated inventory.
* 👑 Top properties by number of superhosts.pdf - Distribution of elite tiers of hosts across properties.
* 📈 avg ratings per city.pdf - Benchmark analysis of general customer satisfaction per municipality.
* 📍 listings per city.pdf - Supply-side distribution showing which markets are most dense.
* 🌙 number of avg maximum nights.pdf - Analysis of booking duration upper limits.
* ⏳ number of avg minimum nights.pdf - Analysis of customer length-of-stay baseline constraints.
* 📉 number of listings per year.pdf - Market growth rate and historical trajectory of platform adoption.
* 🏅 number of superhosts per city.pdf - Density and location mapping of highly rated, reliable hosts.
* 🏢 top properties by number of listings.pdf - Competitive landscape looking at dominant hosts and property portfolios.

### 💡 Key Insights

* **Geographic Variations:** Clear pricing and supply standard differences across global cities highlight distinct local market characteristics.
* **Host Professionalization:** Concentrated numbers of listings among top properties point to a growing professional host ecosystem rather than just casual users.
* **Stay Rules:** Analysis of minimum and maximum night constraints reveals distinct long-term vs. short-term rental strategies across metropolitan areas.
